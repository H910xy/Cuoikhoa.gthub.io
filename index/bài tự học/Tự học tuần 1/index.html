Giới thiệu học phần

Học phần cung cấp kiến thức nền tảng về cấu trúc, nội dung và cách trình bày một trang web bằng HTML và CSS.

Hành trình từ HTML tới một trang web hoàn chỉnh

Mục tiêu học phần

  • Nắm vững cấu trúc HTML và các thẻ ngữ nghĩa cơ bản
  • Sử dụng đúng các thẻ semantic như header, nav, main, section và footer.
  • Biết cách trình bày nội dung bằng CSS và tạo liên kết giữa các trang.
  • Vận dụng kiến thức để xây dựng một trang web hoàn chỉnh.
